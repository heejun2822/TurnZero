## 2. 턴 흐름과 공통 처리

### 2.1. 턴 단계

| 턴 단계 | 처리 |
|---|---|
| 턴 시작 | 턴 번호·사운드 표시, 기본 AP 지급, 일정에 따른 아이템 생성, 남은 쿨다운 갱신. 안내 후 준비 진입 |
| 준비 | 남은 시간 동안 명령 예약·수정·취소, 장비 제작·교체, 수동 카메라 조작 |
| 시뮬레이션 | 입력 잠금 → 행동 페이즈 0~4 처리 → 공개 가능한 기록으로 재생. AP·새 쿨다운은 실제 행동 시작에 적용 |
| 턴 마무리 | 승패 확정, 처치 AP 일괄 지급과 시각 효과, 종료 시점이 된 지대·상태 효과 정리, 관측 표시 정리 |

쿨다운 감소는 턴 시작에 한 번만 한다. 준비 완료 해제·시점 변경·화면 재생 때문에 AP 지급이나 쿨다운 감소를 반복하지 않는다.

### 2.2. 행동 페이즈

| 행동 페이즈 | 현재 행동과 자동 처리 | 판정·재생 경계 |
|---|---|---|
| 0 | 부활 | 복귀 위치와 HP를 이후 행동 페이즈에서 사용 |
| 1 | 은신 이동, 시야 구조물 설치 | 은신은 첫 이동 전 적용. 같은 페이즈 이동은 동시 진행. 새 구조물·시야는 페이즈 종료에 유효화 |
| 2 | 기본 이동 | 스텝별 전체 위치 확정 → 시야/관측 갱신. 같은 스텝 아이템 접촉은 함께 집계 |
| 3 | 기본 공격, 공격형 스킬, 유지 중 불타는 지대 발동 | 유효 공격 모두 보장, 공개 HP는 공격별 갱신, 캐릭터 사망은 페이즈 종료에 일괄 확정 |
| 4 | 위치 교환 → 포털 설치 시작·자동 진행 | 유효 교환은 시작 위치 기준 공통 결과를 쌍별 재생. 새 설치물 생성·포털 완성은 페이즈 종료 |

양측에 공통인 실제 판정과 플레이어별로 공개하는 재생 순서를 구분한다. 공격·교환의 ‘자기 팀 먼저’는 선공권이 아니며, 이동은 양 팀을 함께 재생한다.

### 2.3. 공통 쿨다운

- MOV/ATK/SKL/EQP의 쿨다운은 실제 실행 시 시작한다. 예약·선택·미리보기만으로 시작하지 않는다.
- 실행 전 취소·미실행에는 AP 소비와 새 쿨다운이 없다. 취소 자체로 이미 남은 쿨다운을 초기화하지 않는다.
- 턴 시작에 남은 수를 한 번 1 감소시키며 최소 0으로 제한한다.
- 쿨다운 1은 T턴 사용 후 T+1턴부터 재사용, 2는 T+1턴을 쉬고 T+2턴부터 재사용한다.
- 단일 턴 행동이 시작 후 사망 이외의 사유로 중단되어도 시작한 쿨다운은 유지한다.
- 사망하면 해당 캐릭터의 모든 행동 쿨다운을 0으로 만든다. 장비 교체는 그 장비 행동 쿨다운을 0으로 만든다.
- 포털 후속 진행은 최초 실행의 연속이며 AP·쿨다운을 새로 부과하지 않는다.
- 쿨다운이 남은 행동은 새로 예약할 수 없다. 0이어도 AP·상태 등 다른 조건을 따로 검사한다.
- 3 이상인 새 쿨다운은 콘텐츠를 추가할 때 별도 정의한다.

## 4. 시스템별 요구사항과 규칙

요구사항 ID는 개발·검증 연결에 계속 사용한다. 표는 구현해야 할 동작이며 이어지는 처리 규칙이 정상·예외 조건을 설명한다. 개발 상태와 과거 결정 설명은 별도 문서에서 관리한다.

### 4.1. 편성과 경기 초기화

**시스템:** SYS-PRE. **연계:** 필드·시야·장비.

| ID | 요구사항 |
|---|---|
| R-PRE-01 | 플레이어는 경기 전에 사용할 자기 필드를 구성하고 선택할 수 있다. |
| R-PRE-02 | 경기 전에 플레이어별 캐릭터 5종과 장비 1~5종을 중복 없이 편성한다. |
| R-PRE-03 | 정해진 두 플레이어가 하나의 경기에 참가한다. |
| R-PRE-04 | 경기 시작에 자기 필드의 빈 타일을 선택해 기지를 배치한다. |
| R-PRE-05 | 기지 배치 후 기지가 확보한 시야 안의 자기 필드에 초기 캐릭터들의 위치를 선택한다. |

**편성**

- 캐릭터는 서로 다른 5종을 각 1명씩 출전시킨다. 현재는 정의된 5종을 모두 사용한다.
- 경기 번호는 편성 순서 1~5이며 종류 ID와 별개다. 배치 위치·사망·부활로 번호를 바꾸지 않는다.
- 장비 덱은 중복 없는 1~5종의 제작 가능 목록이다. 현재 정의된 3종 중 1~3종으로 시작할 수 있다.
- 제작해도 덱 목록에서 장비 종류를 제거하지 않는다. 완제품 지급이나 무작위로 뽑는 패가 아니다.
- 경기 시작 후 캐릭터·장비 편성은 고정하며 다음 경기 전에만 바꾼다. 준비 완료 해제로 편성을 다시 열지 않는다.
- 수량 초과·중복·미정의 종류 편성은 경기 시작 전에 거부한다. 계정 보유·해금 상세는 Q-21이다.

**배치**

필드·덱 선택 → 기지 배치 → 자기 필드의 기지 시야 안에 캐릭터 배치 → 첫 턴 순서다. 캐릭터는 기지 타일에 놓지 않으며 다른 캐릭터와 중첩할 수 있다.

배치 제한시간·양측 배치 순서/공개 시점·기지 빈 타일의 세부 조건·시작 재료의 정확한 지급 경계는 미정으로 남긴다. 필드/배치는 Q-20과 연계한다.

### 4.2. 필드와 점유

**시스템:** SYS-MAP. **수치:** VAL-04~07, VAL-13~15.

| ID | 요구사항 |
|---|---|
| R-MAP-01 | 사각 타일의 자기·중립·상대 필드를 연결해 전장을 구성한다. |
| R-MAP-02 | 커스텀 필드를 저장하고 경기 전에 선택할 수 있다. |
| R-MAP-03 | 필드 편집 화면에 중립·상대 필드와 연결되는 경계선을 표시한다. |
| R-MAP-04 | 부시·파괴 가능한 장애물·벽 등의 타일 유형을 검토한다. |
| R-MAP-05 | 거리의 기본 한 칸은 상하좌우 인접 칸이다. 공격·스킬·장비의 지정 사거리는 가로·세로 차이를 합산하는 마름모형으로 계산한다. |
| R-MAP-06 | 기지가 있는 타일에는 캐릭터가 존재할 수 없다. |
| R-MAP-07 | 하나의 타일에 진영과 관계없이 여러 캐릭터가 함께 서 있을 수 있다. 아군끼리·적군끼리·아군과 적군이 섞인 중첩을 허용한다. |
| R-MAP-08 | 각 플레이어에게 자기 필드는 아래쪽, 상대 필드는 위쪽으로 표시한다. |

**거리와 점유**

- 인접 한 칸은 상하좌우이며 대각선은 거리 2다. 지정 사거리는 `abs(dx) + abs(dy) <= 사거리`로 검사한다.
- 이동·이동 스킬의 한도는 출발 칸을 제외한 실제 경로 길이다. 우회·되돌아가기·같은 칸 재방문도 이동한 만큼 센다.
- 기지 타일에는 캐릭터가 존재할 수 없다. 배치·이동·부활·전송·교환에 공통 적용한다.
- 일반 타일에서는 진영과 관계없이 여러 캐릭터가 정지·통과할 수 있다. 캐릭터 점유로 이동을 막거나 자동 우회하지 않는다.
- 각 플레이어에게 자기 필드를 아래로 표시하되 공통 논리 좌표는 같다.
- 자기/상대 필드 12×8, 중립 12×4를 연결한다. 축·좌표 변환·편집 유효성 상세는 Q-20이다.
- 부시·벽·파괴 가능한 장애물은 검토 후보다. 이동·시야 차단·파괴·배치 비용을 정하기 전에는 확정 콘텐츠로 취급하지 않는다.

### 4.3. 턴과 명령

**시스템:** SYS-TURN. **공통 흐름:** [2장](#2-턴-흐름과-공통-처리).

| ID | 요구사항 |
|---|---|
| R-TURN-01 | 턴 시작에 사운드·턴 번호 UI를 표시하고 기본 AP와 해당 턴의 아이템을 지급한다. |
| R-TURN-02 | 준비 단계에 타이머와 수동 카메라를 활성화한다. |
| R-TURN-03 | 준비 중 캐릭터별 행동을 예약·수정·취소하며 한 턴에는 한 행동을 사용한다. |
| R-TURN-04 | 제한시간 만료 또는 양측 준비 완료 시 준비를 한 번만 끝내고 마지막 유효 예약을 확정한다. |
| R-TURN-05 | 행동 페이즈별로 시뮬레이션한다. 이동은 스텝별 동시 판정·재생, 공격·교환은 정해진 순차 재생을 적용한다. |
| R-TURN-06 | 여러 턴에 걸친 효과·설치도 원래 행동 페이즈에서 진행하며 시작·진행·완료·중단을 구분한다. |
| R-TURN-07 | 시뮬레이션 후 턴 마무리에 승패를 검사하고 관측 표시를 정리한다. 전멸·기지 파괴의 상황별 승패는 4.8의 확정 규칙을 적용한다. |

**준비 입력과 마감**

1. 준비 중 캐릭터별 예약은 하나다. 변경은 마지막으로 승인된 유효 상태를 갱신한다.
2. 자기 준비 완료 시 자기 명령·제작·교체를 잠근다. 상대가 준비 중이면 상대 입력은 계속 허용한다.
3. 상대 미완료이고 시간이 남았을 때 자기 완료를 해제할 수 있다. 남은 시간·AP·쿨다운을 다시 초기화하지 않는다.
4. 시간 만료 또는 양측 완료 시 준비를 한 번만 종료한다. 신호가 겹쳐도 확정·시뮬레이션·비용 처리를 중복하지 않는다.
5. 미지정 캐릭터는 AP 0 대기이며 새 쿨다운이 없다. 장비 교체로 취소된 이전 예약을 자동 복원하지 않는다.
6. 마감 뒤 수정·제작·교체 요청은 거절하고 마지막 승인 상태를 유지한다. 거절된 제작으로 재료를 소비하지 않는다.

여러 턴 효과·설치는 해당 행동 페이즈에서 자동 진행하며 캐릭터의 새 예약과 구분한다. 온라인 마감 권위와 지연·접속 중단 처리는 Q-22다.

### 4.4. AP와 비용

**시스템:** SYS-AP. **수치:** VAL-10~12, VAL-21~22, VAL-24~27.

| ID | 요구사항 |
|---|---|
| R-AP-01 | 팀별 AP에 상한·턴별 기본 지급·잔량 이월을 적용한다. 첫 지급 전 0에서 첫 턴 10을 한 번 지급한다. |
| R-AP-02 | 캐릭터와 행동별로 정해진 AP 비용을 적용한다. |
| R-AP-03 | 행동 실행 시 AP를 소비하며 정상 실행한 공격은 적중 대상이 없어도 비용을 소비한다. 앞선 행동 페이즈에서 이미 사망한 행동자와 실행 전 대상 사망으로 취소된 위치 교환은 비용을 소비하지 않는다. 같은 행동 페이즈 상호 공격은 둘 다 실행한다. 이동 시작 후 도중 사망해도 이미 소비한 이동 AP는 환급하지 않는다. |
| R-AP-04 | 적 캐릭터 처치 보상은 같은 적의 동일한 사망 판정을 한 번만 집계하고 모든 행동·비용 처리가 끝난 턴 마무리에 일괄 지급한다. |
| R-AP-05 | 준비 중 플레이어의 행동 예약 비용 합계는 현재 보유 AP 이하여야 한다. 예약 자체로 AP를 실제 차감하지 않는다. |

**예산과 소비**

- 첫 지급 전 보유 AP는 0이며 첫 턴 시작에 10을 한 번 지급한다. 이후 잔량에 턴 지급량을 더하되 25를 넘지 않는다.
- 예약 AP = 자기 팀 예약 비용 합계, 사용 가능 AP = 보유 AP - 예약 AP다.
- 수정 시 기존 예약을 제외한 새 합계를 검사한다. 초과 요청은 거절하고 기존 유효 예약을 유지한다.
- 예약·수정·취소는 예산만 바꾸며 실제 AP는 행동 시작에 한 번 차감한다. 아직 받지 않은 처치 보상을 예약 예산에 포함하지 않는다.
- 정상 실행한 무적중 공격도 비용을 낸다. 실행 전 사망·유효 대상 소멸 등으로 시작하지 못한 행동은 AP·새 쿨다운이 없다.
- 이동 시작 후 사망해도 이미 소비한 이동 비용 전체를 유지한다. 경로 진행 비율로 환급하지 않는다.
- 이미 시작한 포털 설치는 파괴로 중단되어도 시작 비용을 환급하지 않는다.

**처치 보상**

- 적 캐릭터의 동일한 사망은 공격자·적중 수와 관계없이 한 번만 4 AP를 집계한다. 다른 적의 사망은 각각 집계한다.
- 지속 피해 처치는 효과 생성 팀에 귀속한다. 시전자 사망이나 화면 재생 순서로 소유 팀을 바꾸지 않는다.
- 부활 후 다시 사망하면 새 처치 보상을 집계한다. 이미 죽은 대상의 추가 피해는 새 보상이 아니다.
- 기지·설치물 파괴 보상은 0이다.
- 모든 행동·비용 처리가 끝난 턴 마무리에 보상을 일괄 지급하고 상한을 적용한다. 실제 증가량에 맞는 시각 효과를 표시한다.
- 다음 턴 기본 AP 지급과 처치 보상을 구분한다. 결과 UI와 보상 연출 사이의 세부 순서는 UI 보완 범위다.

### 4.5. 이동과 판정

**시스템:** SYS-MOVE. **수치:** MOV-01~05, SKL-02.

| ID | 요구사항 |
|---|---|
| R-MOVE-01 | 같은 행동 페이즈의 일반/은신 이동은 양 팀 캐릭터가 한 이동 스텝마다 최대 1칸씩 동시에 이동하고 각 이동 스텝 위치 확정 후 시야를 갱신한다. |
| R-MOVE-02 | 적 이동은 경로 중 한 번이라도 관측되면 관측된 구간만 재생한다. 최종 위치가 보이는지는 재생의 필수 조건이 아니다. |
| R-MOVE-03 | 같은 행동 페이즈의 일반/은신 이동 판정과 화면을 이동 스텝별로 동시에 진행한다. |
| R-MOVE-04 | 실제 경로의 접촉 시점에 아이템·설치물 연계를 처리한다. |

**경로**

- 일반/은신 이동은 최종 유효 경로의 실제 길이를 검사한다. 미리보기 중 수정했다면 제출한 최종 경로를 기준으로 한다.
- 자동 최단 경로가 여럿이면 공통 좌표의 위 → 오른쪽 → 아래 → 왼쪽 순으로 탐색해 처음 찾은 경로를 선택한다. 화면별 임의 순서나 새 난수로 경로를 바꾸지 않는다.
- 유효하지 않은 최종 경로 제출은 거절하고 기존 유효 예약·예산을 유지한다.
- 고정 상태의 기본 이동·이동 스킬은 금지한다. 적·아군 캐릭터 점유는 경로를 막지 않는다.

**이동 스텝과 화면**

1. 같은 행동 페이즈에서 실행 가능한 양 팀 캐릭터를 모아 한 이동 스텝에 최대 1칸씩 함께 진행한다.
2. 해당 스텝의 모든 위치를 확정한 뒤 각 플레이어의 시야·관측 기록을 만든다. 경로가 끝난 캐릭터는 도착지에서 대기한다.
3. 포털 입구 도착과 즉시 전송 후 출구 시점은 각각 관측 기록을 남긴다.
4. 화면도 같은 스텝을 함께 재생한다. 이동은 넓은 구도와 아군 경로/도착 표시를 사용한다.
5. 적은 경로 중 관측된 구간만 표시한다. 최종 위치가 숨겨져도 관측 구간은 재생하고 숨은 구간·출발지·도착지를 카메라로 드러내지 않는다.
6. 다음 행동 페이즈는 실제 최종 위치를 사용한다. 서로 다른 페이즈의 이동은 한 묶음으로 합치지 않는다.

유효한 피해로 이동 중 HP가 0이 되면 해당 칸에서 남은 경로를 멈추고 사망은 그 행동 페이즈 종료에 확정한다. 현재 불타는 지대에는 진입 피해가 없으므로 지대를 지나가는 것만으로 이동을 중단하지 않는다. 포털 발동 조건은 장비 시스템, 아이템 접촉·경쟁은 아이템 시스템을 따른다.

| R-COMBAT-10 | 기본 공격·공격형 스킬과 불타는 지대는 적 기지·설치물에도 캐릭터와 같은 피해 수치를 적용한다. |
| R-COMBAT-11 | 캐릭터·기지·설치물의 피해 적용 후 HP는 최소 0으로 저장·표시한다. |
| R-COMBAT-12 | 같은 페이즈 공격은 자기 팀 → 상대 팀 번호순으로 재생하고 HP는 공격별로 표시하며 사망은 페이즈 종료에 확정한다. |

**지정과 효과 범위**

- 기본 공격과 공격형 스킬 SKL-01·03·04·05는 최종 예약의 지정 타일에 효과 중심을 고정하며 적을 추적하지 않는다.
- 빈 일반 타일과 밝음·회색·암흑 타일을 지정할 수 있다. 공격 지정·예약만으로 숨은 정보를 공개하지 않는다.
- 유효 예약/수정 시 사거리를 검사한다. 이후 시전자 위치가 바뀌거나 대상 타일 시야를 잃었다는 이유만으로 다시 거리 검사하거나 취소하지 않는다.
- 범위 N은 지정 중심에서 맨해튼 거리 N 이하의 타일이다. 범위 0/1/2/3은 경계에 잘리지 않으면 각각 1/5/13/25칸이다.
- 전장 밖 효과만 잘라내며 중심을 옮기거나 반대편으로 이어 붙이지 않는다. 전장 밖을 새 중심으로 지정하지 않는다.
- 자신·아군 캐릭터·기지·설치물은 피해를 받지 않는다. 같은 타일의 적 캐릭터는 각각 정해진 피해를 받는다.
- 적 기지·포털 입출구·시야 구조물에도 같은 피해 수치를 적용한다. 별도 구조물 배율은 없다.
- 피해 후 HP는 `max(0, 이전 HP - 유효 피해)`다. 새 회복·최대 HP 변경 정책은 추가하지 않는다.
- 고정 부여는 실제 피해를 입은 적 캐릭터에 한정하며 양측 기지·설치물에는 부여하지 않는다.
- 예약 사거리 유지가 사망·고정 등 다른 실행 제약을 무시하는 것은 아니다.

**동시 피해와 순차 재생**

같은 행동 페이즈의 유효 공격을 모두 적용한다. 각 화면은 자기 팀 캐릭터 번호순 → 상대 팀 번호순으로 재생하고 공개 가능한 HP를 공격마다 갱신한다. 중간 HP 0을 이유로 같은 공격 묶음의 유효 공격을 누락하지 않는다.

캐릭터 사망은 행동 페이즈 종료에 일괄 확정한다. 그때 장착 장비 파괴·쿨다운 초기화·뒤 페이즈의 미실행 행동 취소·적 카드 사망 공개를 연결한다. 앞선 페이즈에서 이미 사망한 캐릭터의 일반 행동은 실행하지 않는다. 승패는 턴 마무리 규칙을 따른다.

**불타는 지대**

| 항목 | 처리 |
|---|---|
| 기간 | 생성 턴 T를 포함해 T~T+D-1턴. 현재 D=3이며 5턴 시전이면 5·6·7턴에 유효, 7턴 마무리 소멸 |
| 생성 턴 | 시전 캐릭터의 공격형 스킬 위치에서 1회 피해. 추가 정기 발동 없음 |
| 이후 턴 | 원래 스킬 행동 페이즈의 공통 발동 시점에 범위 안 유효 적 판정 |
| 재생 위치 | 각 화면의 해당 페이즈에서 효과 소유 팀 구간 맨 앞. 이후 그 팀의 새 캐릭터 행동을 번호순 재생 |
| 여러 기존 지대 | 생성 턴 → 시전자 번호 → 생성 식별자의 고정 기준으로 표시. 화면 순서가 실제 피해를 바꾸지 않음 |
| 횟수 | 지대당 대상별 턴 1회. 진입·통과·재진입·턴말 추가 피해 없음 |
| 중첩 | 같은 시전자·같은 타일의 새 지대도 별개. 각 기간/발동 독립, 겹치면 피해 누적 |
| 독립성 | 시전자 사망·부활 후에도 남은 기간 유지. 새 캐릭터 행동을 소비하거나 AP·쿨다운을 재청구하지 않음 |
| 시야 | 이후 자동 발동만으로 새 임시 공격 시야를 주지 않음 |

은신과 고정의 기간·갱신·해제는 [상태 효과](#413-상태-효과)에 둔다. 새 지형의 공격 차단·시선 판정은 Q-06/Q-20에서 추가 정의한다.

전멸로 패배한 뒤 다음 턴 부활 유예를 주지 않는다. 화면의 공격 재생 순서로 결과를 바꾸지 않는다.

**사망과 부활**

- 사망 확정 시 장착 장비 파괴, 모든 행동 쿨다운 0, 사망 전에 예약한 미실행 일반 행동 취소를 적용한다.
- 이미 생성된 지대·시야 구조물·시작한 포털 설치는 각 독립 수명 규칙을 따른다.
- 사망 턴 D 다음인 D+1턴부터 부활할 수 있다. D+1턴 비용은 15, 이후 추가 대기 턴마다 1 할인하며 최소 10 AP다.
- 부활 비용: `max(10, 15 - max(0, 현재 턴 - 사망 턴 - 1))`. T턴 사망이면 T+1:15, T+2:14, T+6 이후:10 AP다.
- 예약과 실제 실행 모두 자기 팀 생존 아군이 1명 이상이고 경기가 진행 중인지 검사한다.
- 자기 필드의 기지 시야 안 일반 타일에 복귀한다. 기지 타일은 제외하며 캐릭터·아이템·시야 구조물과의 공존은 허용한다.
- 죽은 캐릭터 자신의 부활 명령이 그 턴 행동을 사용한다. 행동 페이즈 0에서 최대 HP로 복귀하고 그 턴에 추가 이동·공격·스킬·장비 행동을 하지 않는다.
- 현재·대기 상태 효과를 모두 정리하고 장비·옛 예약을 복구하지 않는다. 쿨다운은 0이다.
- 이후 페이즈 공격의 대상이 될 수 있다. 숨은 부활의 상대 공개는 재관측 때 갱신한다.

### 4.9. 아이템 생성과 획득

| R-ITEM-07 | 암흑 타일의 아이템은 보이지 않는다. |

**보유와 생성**

- 장비 제작 재료·강화 재료·소비 아이템은 팀 공용 인벤토리로 보유하고 종류별 수량을 표시한다.
- 경기 시작에 제작 재료 2개를 한 번 지급한다. 주기 생성의 0턴 보너스로 중복 지급하지 않는다.
- 실제 턴은 1부터 시작한다. 일정이 겹치면 해당 생성들을 모두 평가한다.
- 후보는 캐릭터·기지·기존 아이템·설치물이 없는 이동 가능한 일반 타일이며 생존 캐릭터 하나 이상과 지형상 보행 연결돼야 한다.
- 한 턴 이동력·AP·일시 고정은 생성 접근성 제한이 아니다. 포털만으로 접근하는 고립 칸은 제외한다.
- 후보가 없으면 해당 생성 1회만 생략하며 나중에 보충하지 않는다. 미획득 아이템은 유지하고 별도 개수 상한은 없다.
- 같은 턴·구역에서는 제작 재료 → 강화/소비 후보 순으로 배치하며 새 배치 타일도 후속 후보에서 제외한다.
- 각 구역의 유효 후보에서 균등·독립 추첨하고 경기 시드로 재현한다. 숨은 생성 위치는 관측 정책을 따른다.
- 강화·소비의 구체 종류·효과·종류 선택 확률은 Q-12이며 빈 목록을 임의로 채우지 않는다.

**접촉과 경쟁**

1. 실제 도달한 일반/은신 이동의 중간·최종 타일에서 획득한다. 출발 칸·미진행 경로·서 있는 대기는 획득 접촉이 아니다.
2. 포털은 실제 접촉한 입구와 유효 출구를 검사하며 사이 공간은 검사하지 않는다. 전송 실패면 실제 도착한 입구까지만 검사한다.
3. 정상 부활·위치 교환의 도착도 획득할 수 있다.
4. 실제 판정 시점이 가장 빠른 팀이 획득한다. 이동에서는 행동 페이즈를 먼저, 같은 페이즈에서는 공통 이동 스텝을 비교한다.
5. 같은 스텝의 일반 도착·포털 입구·즉시 출구 접촉을 모두 모은 뒤 지급한다. 그 시점에 양 팀이 접촉했다면 양쪽에 팀당 해당 개별 아이템을 한 번 지급한다.
6. 부활·교환 도착은 해당 공통 판정 묶음의 접촉으로 처리하며 화면의 쌍별/번호순 재생을 선점 기준으로 사용하지 않는다.
7. 접촉 팀을 먼저 확정하고 인벤토리에 즉시 지급한 뒤 실제 아이템을 즉시 제거한다. 같은 턴이어도 나중에 도착한 팀은 받지 못한다.
8. 같은 팀 다수 캐릭터·재방문은 개별 아이템당 1회다. 같은 타일에 여러 개별 아이템이 있으면 각 개체를 모두 별도로 지급한다.
9. 획득 후 사망해도 이미 받은 인벤토리는 유지한다.

자기 직접 획득 또는 현재 관측 화면에는 제거를 즉시 표시한다. 시야 밖 상대 획득으로 회색의 마지막 관측값을 실시간 갱신하지 않는다. 반투명·흐림·턴말 소멸 예고는 사용하지 않는다.

**제작·교체**

- 자기 준비 입력이 허용될 때만 생존 아군에게 제작/교체한다. 자기 완료 상태·마감 뒤에는 불가하다.
- 재료 1개로 자기 덱 장비 1개를 선택해 즉시 장착한다. 캐릭터당 슬롯은 1개이며 미장착 완제품 비축은 없다.
- 제작·교체는 AP와 그 캐릭터의 턴 행동을 소비하지 않는다. 다른 캐릭터에게 장비를 이전하지 않는다.
- 교체는 확인 후 재료를 소비하고 이전 장비와 그 강화 내역을 파괴한다. 환급은 없다. 확인 취소면 재료·장비·예약을 유지한다.
- 교체 시 이전 장비 행동 예약만 취소하고 그 예약 예산을 해제한다. 실제 보유 AP를 추가 지급하지 않으며 다른 종류의 예약은 유지한다.
- 장비 행동 쿨다운을 0으로 초기화해 새 장비를 사용할 수 있게 한다. 실제 사용 후 새 장비의 쿨다운을 시작한다.
- 이미 시작한 포털 설치·기존 포털은 장비 교체로 제거하지 않는다.
- 강화 재료는 장비에 귀속되고 장비당 최대 3회다. 구체 효과·비용·최대 강화 상태 소비 정책은 Q-12다.

**새 설치물의 공통 경계와 경합**

- 새 포털 입출구와 시야 구조물은 설치 행동 페이즈 종료에 생성되고 이후 페이즈부터 공격 대상이 된다.
- 포털은 미완성 상태에도 입구·출구 각각 HP 5로 생성하며 피해를 받는다. 완성할 때 손상을 회복하거나 파괴된 쪽을 복구하지 않는다.
- 회색 타일의 숨은 현재 점유는 실제 실행 때 검사한다. 예약·미리보기만으로 숨은 점유 변화나 현재 정보를 공개하지 않는다.
- 기본 조건을 충족한 같은 페이즈 신규 설치 요청들이 타일을 공유하면 겹치는 요청을 모두 미실행 처리한다. 진영·번호·화면 순서로 승자를 고르지 않는다.
- 이미 기본 조건이 무효인 요청은 유효한 요청과 경합시키지 않는다.
- 포털은 입구·출구 전체를 검증한다. 한쪽이라도 무효면 전체 미실행이며 부분 생성·자동 대체 좌표는 없다.
- 시작 전 미실행에는 AP·새 쿨다운이 없다. 유효 예약의 사거리와 지정 타일은 이후 시전자 위치 변화만으로 다시 검사하거나 옮기지 않는다.
- 설치물과 캐릭터·아이템의 공존은 허용하며 기지·다른 기존 설치물 타일에는 새 포털/시야 구조물을 설치하지 않는다.

**EQP-02: 위치 교환**

- 장착 캐릭터와 자기의 다른 생존 캐릭터를 교환한다. 사거리 제한은 없으며 고정 등 위치 변경 금지 조건을 검사한다.
- 실행 전 시전자/대상 사망·고정 등 기본 무효 요청을 제외한 뒤, 한 캐릭터가 여러 유효 교환에 참여하면 관련 교환을 모두 미실행 처리한다. A↔B와 B↔C, 중복 A↔B도 포함한다.
- 유효 교환의 결과는 해당 행동 페이즈 시작 위치를 기준으로 정한다. 서로 겹치지 않는 교환을 각 화면의 자기 팀 시전자 번호순 → 상대 팀 번호순으로 한 쌍씩 재생한다.
- 대상의 자기 예약은 유지하며 행동을 추가·재실행하지 않는다.
- 같은 타일의 서로 다른 아군도 정상 교환으로 AP 5·쿨다운 1을 적용한다.
- 행동 페이즈 4에서는 유효 교환 뒤 포털 설치 시작/자동 진행을 처리한다.
- 교환 도착은 포털을 발동하지 않으며 아이템 획득은 아이템의 공통 접촉 규칙을 적용한다.

**EQP-03: 은신 간파 시야 구조물**

- 설치 사거리 2, HP 3, 설치 타일 중심 맨해튼 반경 4의 시야·은신 간파를 소유 팀에 제공한다.
- 설치 페이즈 종료에 시야를 활성화하고, 파괴가 처리된 페이즈 종료에 시야를 회수한다. 과거 이동·공격을 소급 공개하지 않는다.
- 간파는 관측 예외이며 은신을 제거하거나 기간을 줄이지 않는다. 유효 시야는 여러 구조물과 기지·캐릭터 시야의 합집합이다.
- 자동 만료·개수 상한은 없고 설치 캐릭터 사망과 독립이다.
- 캐릭터·아이템과 공존하며 정지/통과를 막지 않는다. 밝음·회색 설치 예약을 허용하고 암흑은 금지한다.
- 파괴 후 남은 다른 구조물의 간파까지 제거하지 않는다. 적에게 공개되는 HP·파괴 정보는 관측 정책을 따른다.

**화면 구성**

- 공통: 턴 번호·준비 타이머·준비 완료/해제·양측 닉네임·기지·캐릭터 정보.
- 자기 팀: 최대/예약/사용 가능 AP를 색이 다른 칸으로 구분, 팀 인벤토리 수량, 캐릭터별 장비·상태·예약 표시.
- 선택 상세: 초상화·이름·HP·공개 가능한 상태, 행동 버튼·비용·사거리·범위·효과·소요 턴·현재 예약.
- 생존 자기 캐릭터는 이동·공격·스킬·장비·대기, 사망 자기 캐릭터는 부활을 제공한다.
- 자기 행동 아이콘에는 남은 쿨다운, 상세에는 재사용 가능 턴을 표시한다. AP·상태 제한과 구분하며 입력/표시만으로 쿨다운을 바꾸지 않는다.
- 상대 카드의 정체 공개·관측값·사망·부활 표시는 시야 시스템을 따른다. 숨은 장비·상태·예약을 UI로 드러내지 않는다.
- 처치 AP 지급 효과는 실제 상한 적용 후 증가량과 일치해야 한다. 증가량이 0이면 AP가 늘어난 것처럼 표시하지 않는다.
- 아이템 획득은 인벤토리 수량 갱신과 필드 제거를 같은 판정에 맞춰 표시한다.

**선택과 중첩**

같은 타일의 모델은 타일 안에 작게 분산하되 논리 좌표와 판정은 같은 칸이다. 행동 미지정 상태에서는 모델 클릭/탭으로 직접 선택하고 모델이 없는 바닥을 반복 클릭/탭하면 그 칸의 관측 중 캐릭터를 순환 선택한다. 숨은 적은 선택 목록에서 제외하고 적 선택은 정보 확인용이다. 아군 카드는 명시적인 직접 선택 수단이다.

행동 대상을 지정하는 중에는 전장 모델·바닥 클릭을 그 논리 타일의 대상 지정으로 처리한다. 캐릭터 선택으로 임의 전환하지 않으며 행동별 유효 대상 조건은 검사한다.

**카메라**

필드를 비스듬히 내려다본다. 준비 중 이동·줌을 허용하고 시뮬레이션 중 수동 조작을 잠근다. 이동은 관측 가능한 움직임을 넓게 보여주고 공격·교환은 공개 가능한 재생 대상을 추적한다. 숨은 적·범위를 카메라 목표나 화면 크기 계산에 넣지 않는다. 단축키·드래그 충돌·모바일 상세와 복귀 구도는 Q-18에서 보완한다.

| R-META-01 | 랜덤 뽑기로 타일·캐릭터·장비 아이템 등의 오브젝트를 획득한다. |

타일·캐릭터·장비 오브젝트의 랜덤 획득과 같은 등급의 같은 오브젝트를 합치는 상위 등급 진화를 기획 범위로 둔다. 후보 목록·등급·재화/비용·확률·진화 재료 수·경기 능력 영향·보유 저장과 해금은 미정이다. 인게임 장비 제작 재료와 영구 계정 재화를 같은 상태로 취급하지 않는다.

#### 4.14.1. 경기 설정과 진행

아래 모드 기본값·담당 팀·편성은 첫 구현의 초기 설정 기준이다. 봇이 지킬 경기 규칙과 함께 이곳에서 관리한다.

| 항목 | 초기 설정 기준 |
|---|---|
| 모드 | 설정 화면에서 로컬 2인 / 봇 대전 선택. 기존 기본값은 로컬 2인으로 유지 |
| 담당 팀 | 봇 대전은 사람 P1, 봇 P2. 진영 선택 확대는 후속 |
| 편성 | 봇은 현재 캐릭터 5종과 기본 유효 장비 덱을 고정 사용. 1차에서 제작·장비 행동은 선택하지 않음 |
| 필드 | 사람은 기존 필드 선택, 봇은 기본 필드 프리셋. 사람 배치에 맞춰 봇 편성/배치를 바꾸지 않음 |
| 배치 | 사람의 배치를 마치면 봇 팀의 기지·5명을 지정된 유효 위치에 순서대로 자동 배치 |
| 잘못된 배치 설정 | 자기 필드·기지 시야·타일 조건을 먼저 확인. 실패하면 설정 오류를 표시하고 시작하지 않으며 무한 좌표 재시도 금지 |
| 준비 | 준비 진입 → 봇 관측 고정 → 계획 → 예약 → 봇 완료. 사람이 완료하면 기존 흐름으로 즉시 판정·재생 |
| 조작 권한 | 봇 대전의 정상 조작 시점은 사람 팀. 팀 전환·입력·개발 도구 요청으로 봇 예약/제작/준비 상태를 바꾸지 못하게 함 |
| 디버그 | 전체 공개·시점 검사 도구는 판단 입력과 분리. 봇 의도/점수 확인은 명시적인 개발 진단에서만 제공 |
| 종료·재시작 | 종료 시 새 판단 중지. 재시작은 모드·선택한 시드를 유지하고 기존 계획·턴 처리 표시·탐색 목표·진단 기록을 새 경기로 초기화 |

1. 기존 턴 시작 지급·안내가 끝나 준비에 진입한다.
2. 봇 팀의 공개 관측을 고정해 계획하고, 공용 AP 안에서 명령을 예약한다. 미지정 캐릭터는 기존 무료 대기 규칙을 따른다.
3. 예약을 마친 봇을 한 번 준비 완료 처리한다. 사람의 준비 시간은 기존 제한을 사용하며, 사람이 완료하면 추가 봇 연출 대기 없이 판정·재생한다.
4. 재생 중 판단·예약하지 않는다. 다음 준비 단계에서 새 관측으로 다시 계획한다. 준비 완료 해제·시점 전환으로 같은 턴 계획을 다시 만들지 않는다.

봇이 먼저 완료하므로 사람이 완료하면 양측 완료가 된다. 기존 규칙대로 이후 준비 해제는 불가하다. 사람의 준비 제한을 줄이거나 봇 사고 연출 때문에 준비 시간을 추가하지 않는다. 재생을 건너뛰어도 다음 턴 계획은 한 번만 생성한다.

#### 4.14.2. 정보 제한과 판단 입력

- 판단 입력은 봇 팀의 정상 관측 스냅샷이다. 화면의 시점 전환·전체 공개 디버그 설정과 분리한다.
- 자기 팀의 상태·AP·쿨다운·예약, 공개된 콘텐츠 수치와 필드 규칙을 이용할 수 있다.
- 현재 관측 적과 마지막 관측 적을 구분한다. 마지막 위치·HP는 과거 기록이며 현재 적중이나 처치를 보장하는 값으로 쓰지 않는다.
- 적 종류는 시작부터 알고, 사망은 전역 공개, 시야 밖 부활은 재관측 때 공개한다. R-VIS-04~08과 같은 기준이다.
- 적이 보이지 않으면 마지막 관측 지점을 수색하거나 상대 필드를 탐색한다. 발견한 기지는 공격 목표에 포함하며 숨은 실제 기지 위치로 이동 목표를 정하지 않는다.
- 명령 검증의 거절을 반복해 숨은 개체를 탐지하지 않는다. 관측이 같고 숨은 실제 상태만 다른 경우에도 판단 결과가 같아야 한다.

| 정보 | 판단 입력에 포함 / 처리 |
|---|---|
| 규칙·자기 팀 | 턴·단계, 공개 필드/콘텐츠 규칙, 자기 AP/예약·기지·캐릭터 HP/위치/상태/쿨다운·사망 턴 |
| 관측 가능한 적 | 현재 보이는 적의 공개 상태와 기지·설치물. 공격 평가에는 현재 관측값만 사용 |
| 관측 기억 | 종류·관측 턴·마지막 위치/HP·공개 사망 여부, 기지/설치물 기억. 현재 관측과 별도 구분 |
| 탐색 | 현재 시야·탐색한 타일. 미관측 물체를 실제 필드 상태에서 추가하지 않음 |
| 제외 | 경기의 전체 실제 상태, 상대 예약/AP, 숨은 현재 상태, 디버그 전체 공개 정보, 화면 재생 중간 상태 |

#### 4.14.3. 행동 후보와 팀 계획

행동별 점수·가중치는 [5.8](#58-로컬-봇-행동-평가식과-초기-조정값)을 사용한다. 다음은 후보 생성·AP 배분·중복 피해·탐색의 공통 기준이다.

1. 준비 진입 시 경기 식별자·턴으로 중복 실행을 막고 관측을 고정한다. 사람의 예약이나 화면 갱신으로 다시 계획하지 않는다.
2. 살아 있는 캐릭터마다 도달 가능한 타일의 기본 이동과 사용 가능한 스킬 이동을 만든다. 공격형 행동은 사거리 안의 모든 중심 타일을 검사하되 현재 관측 적에게 효과 범위가 닿는 후보만 점수화한다. 관측한 기지·설치물도 대상이다.
3. 사망 캐릭터는 부활 가능 턴·생존 아군·비용·유효 복귀 위치를 만족할 때 부활 후보를 만든다. 대기는 모든 캐릭터의 기본 대안이다.
4. 전체 미지정 캐릭터의 후보 중 남은 팀 AP로 가능한 최고 점수의 행동을 하나 선택한다. 해당 캐릭터를 제외하고 예상 피해·남은 예산을 갱신해 나머지를 다시 비교한다. 최대 5개 행동을 고르는 유한 반복이다.
5. 점수가 대기보다 높지 않거나 가능한 행동이 없으면 미지정 캐릭터는 대기한다. 처치 AP나 미래 AP를 현재 예산에 더하지 않는다.
6. 계획안을 기존 명령 예약 흐름으로 제출한다. 거절한 명령은 오류 이유를 남기고 그 캐릭터를 대기 처리하며 다른 타일을 반복 제출해 숨은 상태를 탐지하지 않는다. 마감/턴 변경이면 남은 제출을 멈춘다. 기존 유효 예약을 무효 명령으로 덮지 않는다.
7. 여전히 같은 경기·턴·준비 단계이고 마감 전일 때 봇을 한 번 완료한다. 종료된 경기나 이전 턴의 계획은 폐기한다.

후보 수는 현재 전장·행동·도달 타일 안으로 제한한다. 모든 팀 행동 조합·상대 행동·미래 턴을 시뮬레이션하지 않는다. 판단은 준비 진입 때만 하고 HUD 갱신·매 프레임 Update·사람 예약 변경마다 후보를 만들지 않는다.

**행동별 평가 주의점**

| 행동 | 1차 평가 기준 |
|---|---|
| 기본 공격·강한 공격·정밀 타격 | 현재 관측 대상의 실제 효과 범위·HP로 피해/처치 가치를 계산. 지정 타일 고정이며 상대의 현재 예약을 추적하지 않음 |
| 불타는 지대 | 생성 턴의 관측 대상 피해로 평가. 이후 3턴 내내 적이 남아 있다고 가정해 피해를 곱하지 않음 |
| 고정 공격 | 현재 피해와 피해를 받을 생존 적에게 새로 줄 고정 가치를 가산. 이미 예정된 같은 고정은 중복 가산하지 않음 |
| 은신 이동 | 기본 이동과 같은 도달/목표 평가에 은신의 작은 보너스. 고정·거리·AP·쿨다운 제약 준수 |
| 부활 | 기존 비용식과 기지 시야 내 유효 타일 사용. 부활 캐릭터는 그 턴 추가 행동 없음. 현재 AP로 불가능한 부활을 선예약하지 않음 |
| 대기 | 점수 0·비용 0. 쿨다운·고정·예산·목표 부재로 다른 행동이 불리하면 선택 |

예상 중복 피해는 현재 보이는 대상별로 이미 고른 공격 피해만 누적한다. 다음 공격의 유효 피해는 남은 관측 HP까지만, 처치 보너스는 대상별 한 번만 평가한다. 이는 선택용 추정치이며 실제 HP·사망·처치 보상은 기존 시뮬레이션이 판정한다. 같은 페이즈에 적이 먼저 공격하지 못한다고 가정하거나 과거 HP로 처치를 확정하지 않는다.

**이동·탐색 목표**

- 현재 보이는 공격 목표가 있으면 이동 후 기본 공격 또는 스킬이 닿는 위치까지의 경로 거리가 줄어드는 후보를 평가한다. 같은 턴 이동 후 추가 공격을 예약하는 것으로 해석하지 않는다.
- 현재 목표가 없으면 발견한 적 기지, 미해결 마지막 관측 지점, 상대 필드의 미탐색 경계를 수색 후보로 삼는다. 숨은 실제 적/기지 위치를 목적지로 넣지 않는다.
- 마지막 관측 지점을 재관측했는데 비어 있거나 적의 사망이 공개되면 그 지점을 계속 쫓지 않는다. 알려진 경로로 도달할 수 없으면 다른 수색 목표로 바꾼다.
- 팀이 이미 고른 이동으로 확보할 탐색 영역을 감안해 같은 장소에만 몰리는 것을 줄인다. 의도적인 재료 경쟁·위험 회피·후퇴·여러 턴 경로 최적화는 후속 범위다.

#### 4.14.4. 동률 선택과 판단 재현

후보는 캐릭터 번호 → 고정된 행동 순서 → 공통 좌표/경로 순서로 안정적으로 정렬한다. 점수가 같은 후보의 선택만 경기 시드·봇 팀·턴에서 만든 봇 전용 난수로 결정하고, 아이템 생성 등 경기 코어의 난수열은 소비하지 않는다. 같은 입력·코드/콘텐츠 버전·시드에서 같은 결과가 나와야 하며, 프레임 시간·딕셔너리 열거 순서·화면 방향을 동률 시드로 쓰지 않는다.

진단에는 경기/턴·팀·시드·봇/규칙 버전, 사용한 공개 관측, 캐릭터별 행동/대상/경로·점수 항목·선택 이유·예약 성공/거절 이유·총 예약 AP를 남긴다. 기록에 상대의 숨은 실제 상태를 덧붙이지 않는다.

#### 4.14.5. 단계별 범위

봇을 위해 전투 수치·시야·판정 순서·공용 AP·타이머를 변경하지 않는다. 사람은 현재 구현된 제작·장비를 사용할 수 있지만 1차 봇은 제작·장비 사용·재료 선점을 목표로 선택하지 않는다. 이동 중 접촉 효과는 기존 코어대로 적용한다.

| 개발 단계 | 포함 범위 |
|---|---|
| 1차 | 자동 편성·배치, 5종 기본 행동/스킬·부활, 현재 턴 점수 판단, 팀 AP 배분, 정보 제한, 진단·재현, 종료·재시작 |
| 2차 | 제작·장비 사용과 재료 경쟁. 장비를 포함한 밸런스 평가 |
| 3차 | 협공·후퇴·여러 턴 계획·난이도 조절 |

1차의 중복 공격 완화는 현재 관측 HP에 대한 간단한 예상 피해 배분이다. 상대 행동 예측이나 여러 턴 협공 최적화를 요구하지 않는다. 임의의 최대 턴·교착 무승부를 추가하지 않으며 전체 경기 길이 정책은 Q-23에 남긴다.

현재 구현 상태·작업 순서는 [Development.md 5.1](Development.md#51-로컬-봇-1차-개발-계획), 현재 코드 책임·연결은 [GameArchitecture.md 5.1](GameArchitecture.md#51-로컬-봇의-연결-구조), 완료 검증은 [TC-126~143](Verification.md#21-로컬-봇-1차-수용-기준)에 둔다.

| SE-01 | 은신 / SKL-02, 자신 | 실제 실행·첫 이동 전부터 시전 T턴과 T+1턴 마무리까지 | 일반 시야의 상대 관측 제한. EQP-03 유효 시야 안은 간파. 타일/범위 피해 정상 | 공격·장비·피해·간파로 자동 해제/기간 단축 없음. 만료 또는 부활 시 정리. 재부여의 새 공통 중첩 정책은 미정 |
| SE-02 | 고정 / SKL-04, 피해를 입은 적 캐릭터 | T턴 피격이면 T+1턴 시작~마무리 | 기본 이동·이동 스킬·위치 변경 대상 제한, 일반 공격 허용. 현재 턴 행동 소급 취소 없음 | 새 피격 기준 종료 턴 갱신, 기간 가산 없음. 현재 활성 고정 유지. 만료 또는 부활 시 현재/대기 정리 |

은신 사용이 5턴이면 5·6턴 동안 유지되고 6턴 마무리에 끝난다. 고정 피격이 5턴이면 6턴에 적용·종료된다.

자기 팀은 은신 캐릭터의 위치·상태를 확인한다. 은신 만료 후에도 상대가 그 위치를 관측하지 못하면 현재 정보를 새로 공개하지 않는다. 간파 시 현재 관측 정보를 갱신하지만 은신 자체는 유지되며 모든 간파 시야를 벗어나면 남은 기간의 은신 규칙을 적용한다. 은신 중 사망은 일반 사망 공개 규칙을 따른다.

**새 효과 작성 항목:** ID/이름 → 출처/대상/조건 → 적용 시작/기간/만료 → 규칙 영향 → 재부여/중첩 → 해제/부활 정리 → 공개 조건 → 요구사항/검증 ID.

### 5.8. 로컬 봇 행동 평가식과 초기 조정값

다음 값은 조정용 **초기 조정값 / 밸런스 튜닝 전**이다. 상대의 실제 행동·미관측 HP·미래 적중 확률을 입력하지 않는다. 점수는 정수로 계산하며 평가에 쓰는 피해·범위·AP·HP는 콘텐츠/자기 상태에서 읽는다.

| 평가 요소 | 초기 점수 / 산정 기준 |
|---|---|
| 유효 피해 | 현재 관측 잔여 HP까지의 예상 피해 합계 × 4. 캐릭터·기지·설치물 포함 |
| 적 캐릭터 처치 | 현재 관측 기준 처치 가능한 대상 수 × 12. 이미 계획한 공격과 중복 제외 |
| 적 기지 압박 / 파괴 | 기지 유효 피해 × 2 추가, 현재 관측 HP를 소진하는 후보에 40 추가 |
| 새로운 고정 | 피해 후 생존할 관측 적에게 새로 부여하는 수 × 2 |
| 부활 | 20 + 복귀할 캐릭터 최대 HP × 4 |
| 공격 위치·수색 목표 접근 | 목표까지 남은 최단 경로 거리의 감소량 × 3. 도달 불가 목표는 점수화하지 않음 |
| 탐색 | 새로 밝힐 미탐색 타일당 1. 같은 팀 계획의 중복 탐색은 제외 |
| 은신 이동 | 유효 이동 후보에 2 추가 |
| 비용 | 해당 후보의 AP 비용 × 1 차감. 이동·공격·부활 모두 적용 |
| 대기 | 0. 모든 유료 후보의 점수가 0 이하면 대기 |

공격·부활·이동에 해당하는 항목만 더한 뒤 비용을 뺀다. 이동이 만들 다음 턴 공격 피해를 현재 피해 점수로 더하지 않는다. 부활 위치끼리는 현재 관측 적의 공격 위치까지의 접근 거리, 탐색 이득을 순서대로 비교하고 여전히 같으면 공통 동률 기준을 쓴다. 정밀한 생존 예측은 1차에 넣지 않는다.

**행동별 계산식**

```text
공격 점수 = 유효 피해 합계 × 4 + 처치 예상 캐릭터 수 × 12
          + 기지 유효 피해 × 2 + (기지 파괴 예상 시 40, 아니면 0)
          + 새 고정 대상 수 × 2 - AP 비용
이동 점수 = 목표까지 줄어든 경로 거리 × 3 + 신규 탐색 타일 수
          + (은신 이동이면 2, 아니면 0) - AP 비용
부활 점수 = 20 + 부활 캐릭터 최대 HP × 4 - AP 비용
대기 점수 = 0
```

조건부 가산은 조건을 만족할 때만 적용한다. 기지 피해는 유효 피해 합계에도 포함하며 위 식의 기지 항목은 추가 가중치다. 유효 피해·처치의 중복 집계와 이동/탐색 기준은 [4.14.3](#4143-행동-후보와-팀-계획)을 따른다.

### 6.1. 문서의 역할과 갱신

- 이 문서: 현재 게임의 확정 규칙·요구사항·수치·콘텐츠. 같은 규칙은 담당 시스템 한 곳에서 수정한다.
- Development.md: 요구사항별 개발 상태·현재 차이·남은 질문·다음 작업.
- Decisions.md: 결정 이유·대체된 내용·변경 이력·원문 대응.
- Verification.md: TC 기준과 실제 실행 결과. 통과 범위를 해당 빌드·규칙 버전과 함께 기록.
- GameArchitecture.md: 현재 소스의 구조와 명세 적용 지점.
- LocalPlaytest.md: 현재 로컬 씬 실행·조작·편집 안내.
- [Archive/README.md](Archive/README.md): 이전 프로토타입과 재편 전 문서의 보관 목록/수명 판단.

로컬 봇의 요구사항·행동 선택·정보 제한은 4.14, 점수식·초기 조정값은 5.8, 코드 책임·연결 설계는 GameArchitecture.md, 구현 순서·진행 상태·남은 확인은 Development.md에서 관리한다. 초기안도 담당 문서 안에서 상태를 표시하며, 계획한 타입이나 버튼을 현재 구현으로 설명하지 않는다.

규칙 변경 시 현재 항목을 직접 고치고 → 관련 수치·개발/검증 항목을 갱신하고 → 변경 이유와 영향 ID를 Decisions.md에 남긴다. 삭제된 ID는 재사용하지 않는다. 원문이 바뀌면 해당 ID에 반영하고 원문 해시/행 기준을 갱신한다.

현재 명세와 원문이 다를 때는 사용자 후속 결정이 반영된 이 문서를 개발 기준으로 삼는다. 원문의 과거 표현과 현재 규칙을 동시에 적용하지 않는다. 문답 기록과 재편 전 상태는 보관 문서에서 확인한다.
