## 1. 현재 위치

로컬 인게임은 사람 2명을 번갈아 조작하거나 사람 P1 대 봇 P2로 배치 → 준비 → 판정/재생 → 종료 → 재시작을 시험하는 단계다. 12×20 필드·5종 캐릭터·기본/스킬/장비 행동·부활·제작·관측·HUD가 연결되어 있다.

확정된 로컬 전투 규칙의 PT-01~14 차이를 이번 작업에서 반영했다. 구현한 범위와 자동 검사의 범위는 아래에 구분한다. 강화/소비 콘텐츠·게임 내 필드 저장·온라인·성장은 아직 남아 있다. 게임 규칙은 DevelopmentPlan.md를 계속 기준으로 삼는다.

| 확인 범위 | 현재 연결 | 남은 범위 |
|---|---|---|
| 편성·필드·배치 | 5종 캐릭터·중복 없는 장비 1~5종 덱, 필드 프리셋 선택·수동 배치 | 게임 내 필드 편집/저장·Q-20 배치 세부 |
| 턴·AP·전투 | 페이즈 0~4, 실행 비용·범위·공격별 HP·종료 사망·처치 AP 효과 | 전체 TC 수용 플레이, 신규 피해/이동 기능의 추가 경계 |
| 스킬·상태 | 공통 상태 효과, 은신·고정·지대 발동, 시야 구조물 간파 | 새 효과별 콘텐츠 정의·확장 시 회귀 |
| 아이템·장비 | 최초/동시 접촉·즉시 제거, 3종 장비·경합·설치 종료 경계 | Q-12 강화/소비 목록·생성·사용·강화 |

## 6. 문서 관리

규칙·수치 수정은 DevelopmentPlan.md, 결정 이유는 Decisions.md, 실제 실행 결과는 Verification.md에 기록한다. 이 문서에는 진행 상태와 남은 일을 남긴다.

GameArchitecture.md는 구조/호출 관계를 바꿀 때, LocalPlaytest.md는 실행·조작·데이터 편집 방식이 바뀔 때 함께 갱신한다. 이전 프로토타입은 회귀용 보관 자료이며 현재 규칙의 근거로 사용하지 않는다.
